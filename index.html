Web Programming Practical Project Collection

This website contains five practical projects developed as part of the BCA Cyber Security Web Programming coursework.

Each practical demonstrates the use of HTML, CSS and JavaScript to create interactive, responsive and user-friendly websites.

HTML

Used to create the structure, forms, sections, tables and content of the webpages.

CSS

Used to create professional layouts, responsive designs, cards, navigation and visual styling.

JavaScript

Used for form validation, calculations, dynamic greetings, dynamic content and interactive features.
